### Project Set-Up
>[!NOTE] Bash
```
sh <(curl https://create.tauri.app/sh)
```
>[!NOTE] npm
```
npm create tauri-app@latest
```
>[!NOTE] bun
```
bun create tauri-app
```

> [!NOTE] Dependencies
```
sudo pacman -Syu
sudo pacman -S --needed \
  webkit2gtk-4.1 \
  base-devel \
  curl \
  wget \
  file \
  openssl \
  appmenu-gtk-module \
  libappindicator-gtk3 \
  librsvg \
  xdotool
```
